2. Что пользователям не хватает того, что умеют аналоги (раздел 3): chsrc уже умеет замерять скорость и переключать много целей.

### 2.3. Почему продукт не умирает вместе с инцидентом

- Постоянная аудитория вне РФ (раздел 1G), корпоративные сети.
- CI: режим `env` и `doctor` полезны любой команде, которой важны воспроизводимые сборки при сбое реестра (A10).
- Откат (C4, F1) нужен после **любого** временного переключения.

### Чем отличается mirrorwise

1. **Измеряет, а не предполагает**: проба из сети пользователя, классификация этапа сбоя (`dns`/`connect`/`tls`/`http`/`content`/`timeout`/`proxy`), проверка содержимого (captive-портал отвечает 200).
2. **Сначала официальный реестр**: здоровый источник не трогается; зеркало, поставленное инструментом, снимается, когда реестр восстановился (прямой ответ на C4 и F1).
3. **Безопасность изменения**: https-only, атомарная запись, резервные копии с манифестом, откат байт в байт, предупреждение о переменных окружения, уровни доверия (community-зеркала выключены по умолчанию).
4. **Один файл и ноль зависимостей**: `mirrorwise.pyz` работает там, где `pip install` сломан.
5. **Режим для CI** (`env`) и проверяемые данные (`lint-data`, обязательные ссылки-доказательства).

Что **не** является отличием: скорость замера и количество экосистем — тут chsrc сильнее (65+ против 5).

## 4. Риски и открытые вопросы

| Риск | Что делаем |
|---|---|
| Данные о зеркалах неподтверждены (`confirmed: false`), пути могут расходиться (в каталоге два варианта пути Яндекса, оба помечены) | Проба на стороне пользователя решает; шаблон issue требует вывод `probe`; в README написано прямо |
| Зеркало как третья сторона может подменить пакеты | Уровни доверия, community выключены по умолчанию, совет по хешам в lock-файлах |
| Спрос эпизодический (раздел 0) | Позиционирование шире, чем «российские блокировки»: CI, откат, корпоративные зеркала |
| Совпадение имени `mirrorwise` | Поиск 17.11.2026 явных совпадений не показал; **проверить вручную** страницу `pypi.org/project/mirrorwise` и GitHub перед публикацией (автоматическая проверка PyPI запрещена robots) |
| Windows/macOS | Код учитывает пути, но автор проверял только Linux (3.11–3.13); CI-матрица заработает после первой публикации, возможны правки |
